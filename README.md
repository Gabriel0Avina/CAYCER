# CAYCER - Ingeniería y Metrología

![CAYCER Logo](/public/favicon.png)

## Excelencia en Metrología Industrial

CAYCER es una empresa líder en servicios técnicos especializados para la industria, con más de 15 años de experiencia garantizando la precisión y el cumplimiento normativo en procesos críticos.

### Nuestros Servicios Principales

- **Metrología y Calibración**: Servicios certificados con acreditación EMA (T-225) y trazabilidad al CENAM.
- **Calificación de Equipos**: Aseguramiento técnico de instalaciones y equipos (DQ, IQ, OQ, PQ) bajo normas internacionales.
- **Validación de Procesos**: Evidencia científica de consistencia y calidad en procesos farmacéuticos e industriales.

### Especialidades Técnicas

- **Temperatura y Humedad**: Rangos acreditados para control térmico riguroso.
- **Presión y Vacío**: Calibración de instrumentos con alta precisión.
- **Sistemas HVAC**: Clasificación de áreas limpias e integridad de filtros.
- **Cadena de Frío**: Validación de transporte y almacenamiento crítico.

## Información Técnica del Proyecto

Este sitio web está construido con tecnologías modernas para ofrecer una experiencia rápida y profesional.

- **Frontend**: React + TypeScript + Vite
- **Estilos**: Tailwind CSS + Framer Motion (Animaciones)
- **SEO**: Optimización dinámica con `react-helmet-async`
- **Despliegue**: Preparado para Vercel / Netlify

### Instalación Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```
